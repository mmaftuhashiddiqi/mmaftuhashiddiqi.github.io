Portfolio

Project yang Pernah Dikerjakan

Berikut ini adalah beberapa project yang pernah saya kerjakan, baik secara individu maupun dalam tim.

1st Project - Laptop E-Commerce Website

Project ini dibuat secara individu dengan menggunakan PHP, CSS, JavaScript, dan SQL sebagai databasenya. Hasil dari project ini merupakan sebuah website E-Commerce sederhana untuk penjualan laptop yang terdiri dari dua website untuk user dan untuk admin. Terdapat beberapa fitur pada website tersebut, salah satunya yaitu CRUD.

2nd Project - Snake Game Desktop App

Project ini dibuat secara individu dengan menggunakan Python dan terdiri dari beberapa package, di antaranya yaitu pygame, customtkinter, tkinter, pillow, numpy, bcrypt, dan sqlite3 untuk menyimpan databasenya. Hasil dari project ini yaitu sebuah aplikasi desktop snake game sederhana yang terdiri dari login & register page, main game, main menu page, dan leaderboard page.

3rd Project - CNN untuk Klasifikasi Penyakit Paru-paru

Project ini merupakan project skripsi saya yang dibuat menggunakan Python dengan library Tensorflow. Dataset yang digunakan merupakan data rontgen dada yang diperoleh secara publik dari website Mendeley Data. Project ini menerapkan Machine Learning (ML) dengan metode Convolutional Neural Network (CNN) untuk membuat model yang mampu mengklasifikasikan penyakit paru-paru yang terdiri dari pneumonia, COVID-19, tuberculosis, dan paru-paru normal berdasarkan citra rontgen dada.
